# 0.5.2 每日复盘增量验收

日期：2026-10-07。基于 0.5.1 / 合同 v1.1，增加个人日常复盘，不改变交易策略或原始合同。下文测试数量和运行状态为交付时保存的证据；后续文档补充不表示重新执行测试或实时检查服务。使用入口见 [每日复盘指南](DAILY-REVIEW.md)，配置与归档排障见 [运行配置](EXECUTION.md#每日复盘配置) 和 [运维手册](OPERATIONS.md#每日复盘运行检查)。

## 实现范围

- 左侧“每日复盘”入口，按北京时间选择日期、币种及累计范围。
- 只读完整 SQLite 历史，按预测 / 订单 / 交易身份去重，分页不截断统计；分页与完整 JSON 导出锁定相同证据快照。
- 开场等级与预测终止结果分开，信号 / 数据失效单列，独立到期观察不覆盖原标签。
- 执行去向、未执行原因、影子准入、订单状态和成交结果关联展示；缺少证据时保留未知，不猜测人工未确认。
- 机会按开场日，交易按平仓日；跨日未结束保留待完成。已知资金费修订替换原交易，不重复计数。
- 行情来源、PAPER / 交易所模拟 / 真实资金、场所及模型 / 配置版本分组。无成交时收益指标保持未知。
- 净损益、平均每笔、盈利比例、已平仓净损益回撤、成本偏差，以及有效结果的目标触达率、开场概率校准误差。
- 确定性诊断提示数据 / 样本缺口与待核查方向，不自动改模型、放宽门槛或开启交易。
- 核心启动及每 300 秒检查并归档上一北京时间自然日；真实与合成行情分目录，原子写入、重复运行不覆盖。离线 CLI 与 API 复用汇总代码。

具体统计定义及文件路径见 [每日复盘指南](DAILY-REVIEW.md)。旧 0.5.1 工程与市场验证边界见 [v1.1 验收](ACCEPTANCE-v1.1.md)。

## 验证

新增 Rust 复盘回归覆盖：北京时间日界、跨日待完成与平仓日分离、重复预测 / 结果去重、冻结开场等级、独立到期观察、影子准入不冒充执行、部分成交及未成交、超过 500 条历史、分页快照、交易所环境冻结、资金费修订、行情来源隔离、已平仓净损益曲线、组合阻止与人工跳过、无交易不填造零收益、校准样本筛选、只读及归档幂等、模式变化后的真实准入优先级。

新增浏览器回归覆盖复盘展示、完整导出与分页快照、手机布局与错误状态、真实 API 查询及不修改交易配置。共验证 129 项 Rust（完整运行 128 项通过，最后复盘组 11 项通过，含新增 1 项）、16 项 Python、27 项浏览器测试。浏览器完整运行 26 项通过，开发热更新时失败的旧设置测试与 4 项新增复盘测试复跑均通过。Rust fmt / Clippy、前端类型 / 格式 / 生产构建、旧版与事件驱动两套黄金回放均通过。上述 129 / 27 项为完整运行与后续复跑合计验证的独立用例数量。

最终测试数量与运行证据保存在 [验证摘要](evidence-v0.5.2/validation.json)。

真实数据库累计导出曾读取 3,160 条正式预测、3,158 条结束结果，其中 336 条有效结果；与独立只读 SQL / ID 去重计数一致。该报告包含 31 个币种 / 模型 / 配置分组，不能与当前单一版本样本数混用。无成交样本，报告没有生成盈利或实盘就绪结论。完整个人报告位于 `data/review-exports/`，不纳入 Git。

## 边界

历史日报是截至当日结束时的证据，后续结果或账务修订在新累计报告中查看。自动任务只补上一日，长期停机的更早日期可手动导出。已平仓净损益回撤不含浮动盈亏，不等于账户权益回撤。

该模块不替代全量行情序列审计、离线训练、Shadow 或交易所账户联调。多币长期 OBSERVE/PAPER、12 槽位持续负载与受控小额实盘证据仍未取得。本次没有配置私有凭证或发出真实资金订单。
