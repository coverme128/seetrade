## 核心测试覆盖

- Binance snapshot 首次衔接、增量删除、pu 断档检测和恢复；OKX 前序序列匹配与序号重置。
- 陈旧 / 交叉 / 非法盘口失效，First-hit 只关闭一次，超时后的触达不能覆盖结果，跳空尾损不截断。
- 正向高概率但负 Net EV 拒绝；缺校准 / LOW Trust 拒绝；杠杆、流动性、日亏损、回撤与全账户暴露上限。
- 模型健康降级不改模型权重；演示模型不能加载到真实来源；错误配置不能修改已有状态。
- 模拟入场必须是新合格预测，完整 Prediction → Qualification → Plan → Execution 关联。
- 部分平仓保存剩余数量；数据过期不伪造成交；有效报价恢复后退出；亏损不加仓；kill 的 hold / flatten 行为明确。
- SQLite 提交确认、恢复风险状态、独立注释读取；重启自动回到 OBSERVE。
- 研究数据时间切分清除越界标签；校准降低过度自信；逻辑回归实际拟合；真实 / 演示数据严格隔离；完整报告生成。
- FLAT 不创建方向预测、滞回规则、生命周期审计、原卡保留与冷却、旧 checkpoint 默认字段恢复、训练分布异常与稀疏状态拒绝；总体正常不能掩盖当前状态校准恶化。
- 三轮真正重新拟合、时间边界清除、不重叠测试；修改未来数据不会改变训练权重、分布或校准参数。
- Shadow 不修改 Champion 的预测 / 损益、不执行订单；不追补旧预测；文件 hash / 来源 / 时间 / 指标不符时原子拒绝。
- 样本不足、某窗口亏损、稀疏状态、证据过期、数据失效均阻止晋升；明确操作后晋升 / 回退仍为 OBSERVE，账户损益保留。
- Shadow 跨 checkpoint 精确恢复、重启在途样本失效、配置变动暂停；对比门槛 READY 不会自行切换模型。
- UI 拒绝错误工件且保持当前模型、证据不足时禁用晋升、提交准确 run ID；首份状态延迟到达时设置表单仍初始化。
- UI 原预测卡转结果、查看详情、下一条预测替换、中性状态显示。
- UI 交易对切换、模式切换、kill、配置持久化、健康 / 历史页面；跨来源控制拒绝，直接请求 AUTO 也拒绝。

## 本次逐项核查补充

原始合同保留为需求基准，README 和架构说明描述当前实现；二者不能视为同一份“全部已完成”的清单。以下记录本次继续实现后的状态；剩余代码缺口不能仅靠继续运行或积累更多行情自动补齐：

- **预测生命周期（本次已补）**：中性与滞回、候选确认、资格 / 计划中间状态审计、跟踪 / 完成、原卡结果与冷却均已接入。资格中间状态按实际检查在同一次计算内产生，不保证逐个显示一秒；未通过资格仍可创建观察预测。
- **条件概率**：评分基线的 logits 没有显式建模 horizon / target / stop；离线工具可以对固定定义的数据拟合与校准，但不能将默认原始输出视为经过验证的条件概率。对所有候选期限 / 屏障的研究搜索也未实现。
- **校准与 OOD（本次已补基础实现）**：按标的训练特征分布检查最大标准化偏差；以训练集波动 / 价差边界分组，仅用校准集拟合各组温度；运行时显示组内样本与 ECE。缺少分布或分组证据时硬拒绝。分组规则和逐特征 z-score 是当前研究方法，不能代替真实数据有效性验收。
- **受控研究（本次部分补齐）**：三轮扩展训练窗口，每轮重新训练与校准，清除训练 / 校准跨界标签，测试段不重叠。最后一轮模型连同未见测试结果导出。已补实时配对影子预测、独立记录、整体 / 三窗口 / 市场状态比较、服务器复核后的手动晋升与回退；直接引擎 `--model` 绕过证据加载已停用。定时调度、影子成交和实盘晋升证据仍缺失。
- **实盘与执行**：真实订单鉴权、Execute / Skip、私有订单流、撤单、持仓对账、交易所精度 / 最小下单量 / 保证金规则和 AUTO 均未实现。当前 kill、部分成交和退出验证仅适用于本地模拟引擎。

## 运行与回滚

启动和测试命令见 [README](../README.md)。`./scripts/dev.sh` 启动公共真实行情，`--demo` 使用独立合成行情数据空间。真实行情不会因断网而被演示行情替换。

回滚模型：完成过一次手动晋升后，在 OBSERVE、无模拟持仓且存储健康时使用“模型健康 → 回退上一个模型”。核心核对当前工件 hash，恢复保存的前一模型并结束在途预测；账户损益、配置及历史不重置。只保留最近一代回退，不提供自动回退或随意加载任意模型。旧 checkpoint 中的原模型继续恢复；引擎 `--model` 已停用，候选须经过“导入 → Shadow → 比较 → 晋升”。独立数据目录可以重新观察默认基线，但会建立新模拟账户，并非账户内回退。

运行环境、账户凭证要求和原始概率的解释见 [README](../README.md)；基线权重、概率计算、实时更新与离线验证边界见 [架构说明](ARCHITECTURE.md#标签与模型)。这些内容描述实现行为，不改变本文已执行的测试或真钱门槛结论。
