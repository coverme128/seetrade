# v1.1 Rollout

## Stage 0 — Schema only
Apply additive schema/profile changes and verify v1.0.4 event-driven runtime behavior unchanged for BTC/ETH.

## Stage 1 — Scanner dry run
Scanner writes observations only. No lifecycle promotion.

## Stage 2 — Candidate collection
Allow DISCOVERED/COLLECTING assets. No trading.

## Stage 3 — OBSERVE
Promote selected assets to OBSERVE after qualification/calibration evidence.

## Stage 4 — PAPER
Enable paper execution for explicitly reviewed ELIGIBLE assets.

## Stage 5 — Portfolio Gate enforcement
Run shadow comparison first, then make it mandatory before live.

## Stage 6 — Controlled live
One or a few assets at a time, conservative leverage/risk caps, explicit mode permission.

## Stage 7 — Broaden universe only with evidence
Do not increase universe breadth and leverage simultaneously. Change one risk dimension at a time so realized performance remains attributable.
