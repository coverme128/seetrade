# v1.0.3 Acceptance

The build is acceptable only when all v1.0.2 acceptance items remain PASS and all below are PASS:

- [ ] `QUALIFIED` does not directly produce an AUTO live order.
- [ ] AUTO new-entry path requires `AutoTradeAdmissionDecision=ADMITTED`.
- [ ] A Qualified Episode can be `SKIPPED` and still close to an objective Prediction Outcome.
- [ ] AUTO uses a stricter/versioned Net EV threshold than or equal to standard Qualification.
- [ ] Admission rechecks the latest Evaluation immediately before order creation.
- [ ] Model Trust / execution health / risk budget failures block Admission.
- [ ] Concurrent candidates under constrained budget are selected deterministically and auditable.
- [ ] Re-entry cooldown / fresh-alpha guard prevents churn.
- [ ] `max_daily_trades` is enforced only as a cap and never causes a trade.
- [ ] Every AUTO live entry can be traced through PredictionEpisode → Qualification → Admission → Risk → TradePlan → Execution.
- [ ] AI/LLM cannot change Admission outcome.
