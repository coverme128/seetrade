- [ ] Alpha evaluation runs at configured ~1s cadence.

- [ ] Formal Episode count is not equal to evaluation tick count.
- [ ] OBSERVE Episode closes automatically from market data.
- [ ] TARGET/STOP/TIMEOUT ordering is deterministic under replay.
- [ ] MFE/MAE/final move are recorded.
- [ ] Prediction Outcome is queryable without a Trade.
- [ ] Trade Outcome, if present, is stored separately.
- [ ] Calibration and Model Trust use closed Episode samples.
- [ ] UI shows stable active cards and moves completed Episodes to History/Review.
- [ ] Existing v1.0.1 risk/AI/qualification invariants remain PASS.
